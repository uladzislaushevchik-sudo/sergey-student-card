# Карточка ученика — Сергей Давидовский

Полная карточка находится в `index.html`. Для автоматического расписания используйте Netlify Function.

## Автоматическое расписание из Todoist

Функция `netlify/functions/schedule.js` отдаёт только будущие задачи, у которых одновременно:
- название точно `Занятие с Сергеем Д`;
- метка `Английский`;
- задана дата занятия.

Задачи с названием `Занятие с Сергеем` (без буквы «Д») не попадут в расписание. Часовой пояс карточки: `Europe/Minsk`.

### Настройка Netlify (нужна один раз)

1. В Netlify подключите этот GitHub-репозиторий как источник сайта. Для текущего сайта, опубликованного через Netlify Drop, сначала проверьте, что подключение репозитория не заменит нужный production-сайт неожиданной версией.
2. В настройках сайта откройте **Environment variables** и добавьте `TODOIST_API_TOKEN` со своим Todoist API token. Не помещайте токен в HTML, GitHub или публичные файлы.
3. Убедитесь, что Netlify использует `netlify.toml` из репозитория и публикует `index.html`; каталог функций задан как `netlify/functions`.
4. После успешного деплоя откройте `/api/schedule` на домене сайта. Должен вернуться JSON с `student`, `timezone`, `lessons` и `updated`. Если функция не настроена, карточка попробует запасной источник `schedule.json`.

### Резервный режим

Если API недоступен, HTML пробует загрузить `schedule.json` из той же папки. Этот файл не является живой синхронизацией с Todoist; он используется только как запасной источник.

## Структура

- `index.html` — полная карточка ученика.
- `schedule.json` — резервное расписание.
- `netlify/functions/schedule.js` — безопасный серверный запрос к Todoist.
- `netlify.toml` — настройка функции и маршрута `/api/schedule`.
